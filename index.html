绑定步骤（每台机器人各一次）

  1. 在对应机器人卡片点「生成配对码」。
  2. 用你的 QQ 私聊该机器人，发送页面显示的 /bind 码。两台机器人的码不同，不能混用。
  3. 卡片显示「已绑定」后，点「发送测试」并在 QQ 中确认收到。

提醒阶段

按任务设置的提前天数开始：首次提前 N 天 → 提前 3 天（若更近）→ 提前 1 天 → 当天 → 逾期 1 / 3 / 7 天。越临近措辞越紧迫；完成任务、关闭提醒或删除任务后停止。

重要限制

  • QQ 主动消息受会话窗口、平台权益和配额限制；接口受理不等于已送达。长期未交互请先给机器人发一条消息。
  • 提醒由云端服务执行，关电脑不影响；但服务或网关异常时会暂停并合并补发最近阶段。
  • 配对码 10 分钟有效，请勿截图或外传。

CALENDAR FILE

导出全部已确认日期的未完成任务为 .ics，一次性导入系统日历；不是订阅，网页修改不会自动同步。QQ 阶段提醒由云端独立执行，与 ICS 互为备份。

FILE IMPORT

新文件批量导入

把新资料放进学期文件夹后，对 agent 说「调用 semester-task-import Skill」，它会扫描新增和修改的文件、语义提取任务，并根据课表把“下周 / 下次课 / 第 N 周”等转换为具体上课时间，再经 API 去重导入。

支持的格式：TXT / Markdown / CSV / DOCX / PPTX / 可提取文本的 PDF。扫描版 PDF 和图片会标记待核对，不会伪装成功。
